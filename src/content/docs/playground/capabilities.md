# プレイグラウンドの対応機能

## 操作

| 操作       | WASM API | プレイグラウンド | 備考                                                       |
| ---------- | -------- | ---------------- | ---------------------------------------------------------- |
| `parse`    | 対応     | UIから未使用     | 宣言情報を返します。                                       |
| `lint`     | 対応     | 実行時に使用     | 診断一覧を返します。                                       |
| `format`   | 対応     | 整形操作で使用   | 整形したソースを返します。                                 |
| `completion` | 対応   | 補完操作で使用   | ソース位置に応じた候補を返します。                         |
| `definition` | 対応   | F12・Ctrl/Metaクリックで使用 | 同じプロジェクト内の宣言位置を返します。                   |
| `hover`   | 対応     | ソース上のHoverで使用 | 宣言の名前、シグネチャ、明示した型注釈を返します。          |
| `check`    | 対応     | UIから未使用     | Artifactを評価し、Kubernetesリソースの検証結果を返します。 |
| `evaluate` | 対応     | UIから未使用     | Artifactとレンダリング後のバイト数を返します。             |
| `render`   | 対応     | 実行時に使用     | Artifactを検証してYAMLへ変換します。                       |

上表のWASM APIはWorker実装が受け付ける操作です。公開サイトで実行するには`mcl.wasm`と`wasm_exec.js`が必要です。Playgroundの実行ボタンは`lint`と`render`を順に呼び出します。`parse`、`check`、`evaluate`はAPIで利用でき、画面には操作がありません。

## 入力と外部機能

| 機能                              | 対応状態 | 備考                                                                                                   |
| --------------------------------- | -------- | ------------------------------------------------------------------------------------------------------ |
| MCLソース                         | 対応     | `main.mcl`は64 KiBまで編集できます。                                                                   |
| 相対import                        | 対応     | プロジェクトフォルダー内のMCLファイルを読み込みます。                                                  |
| YAML・Schema・Manifest・Chart     | 対応     | 選択したプロジェクトフォルダーまたはZIP内のファイルを読み込みます。                                    |
| Helm・Kustomize・Manifest adapter | 対応     | 入力ファイルをプロジェクト内に含めてください。                                                         |
| HTTPSやOCIからの取得              | 非対応   | Kubernetes APIサーバーやChart Registryへ接続しません。必要なChartは先に取得してフォルダーへ含めてください。 |

プロジェクトは最大4,096ファイル、各ファイル16 MiB、合計32 MiBまでです。フォルダーの読み込みとZIPの読み込み・書き出しに対応します。評価は4秒まで、レンダリング出力は1 MiBまでです。時間上限を超えたWorkerは終了して再作成します。
